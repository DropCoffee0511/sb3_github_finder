무엇을 어떻게 검색하나요?

검색창 하나로 개발자 프로필과 전 세계 인기 저장소를 스마트하게 자유자재로 탐색해 보세요.

  • 👤 개발자 검색: 앞에 @를 붙여주세요! 예를 들어 @github 또는 @torvalds처럼 검색어 맨 앞에 골뱅이(@) 기호를 달아 입력하시면, 해당 개발자의 와이드 프로필 통계와 스타 기준 인기 저장소를 매핑해 드립니다.
  • 🏷️ 기술 주제(Topic) 검색: 그냥 단어를 쳐보세요! 골뱅이(@) 없이 react, python 등의 IT 기술명을 그냥 입력하시면, 해당 주제를 품고 있는 전 세계 인기 오픈소스들을 3열 4행(총 12개!) 박스 레이아웃으로 가득 채워 드립니다!
  • 아래의 추천 키워드를 클릭해 보세요! 어떻게 검색할지 감이 오지 않으신다면 @github (사용자) 혹은 machine-learning (주제) 배지를 콕 클릭해 보세요!
